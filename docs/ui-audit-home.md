## 2. Структура страницы (сверху вниз)

1. **Герой-секция** — заголовок сезона, описание, 2 CTA (`/pilots`, `/circuits`), счётчики «X пилотов / Y трасс / Z трофеев». Справа: hero-cover (`/gifs/hero-cover.jpg`) c overlay-анимацией (`/gifs/hero.gif`) и плашка BHR с тремя метриками в `brand-gradient`.
2. **Радио** — `RadioPlayer` отдельной секцией.
3. **Сводка** — `card` из 3 колонок `Stat` (отображается только при наличии данных).
4. **Интерактивная пара** — `StandingsPreview` (топ-3) + `RaceWeatherCard` (ближайший этап, температура, дождь, обратный отсчёт).
5. **Пилоты** — `SectionHeading` + сетка до 6 `PilotCard` (sm:2, lg:3).
6. **Календарь трасс** — `SectionHeading` + сетка до 3 `CircuitCard`.
7. **Лента новостей** — список из 5 последних постов с обложкой и категорией.
8. **Зал славы** — 4 записи в 2 колонки.
9. **BhrPlate** — промо-блок «Заказать рекламу» + повторный `RadioPlayer`.
10. **Реклама** — `AdTile` (ротация баннеров) + служебная строка-ссылка на журнал.

**Что работает:** строгая вертикальная иерархия, единые `Section` (`py-14 md:py-20`), предсказуемая сетка, повторяющиеся паттерны «eyebrow → H2 → description → outline-action».

## 3. Что хорошо работает

### 3.1 Дизайн-система
- Чёткие семантические токены (`bg`, `surface`, `fg`, `muted`, `brand`, `brand-soft`, `line`, `violet`, `cyan`, `gold`).
- Светлая и тёмная темы описаны полностью, включая `shadow-card`, `shadow-nav`, радиусы.
- `prefers-reduced-motion` уважается глобально (`index.css:193–202`).

### 3.2 Типографика
- Дисплейный шрифт для заголовков, sans для текста, mono для цифр через `--font-mono`.
- Большой заголовок героя использует `clamp(1.9rem,5.5vw,3.25rem)` + `text-balance` + `tracking-[-0.035em]` — выглядит сильно на любом экране.
- `tabular-nums` на счётчиках и баллах — цифры не «прыгают».

### 3.3 Компонентная база
- `Section`, `Container`, `SectionHeading`, `Reveal`, `Stat`, `Spinner`, `EmptyState` — единый набор примитивов.
- `ButtonLink` поддерживает `to`/внешнюю ссылку, 6 вариантов и 3 размера; `active:scale-[0.97]` + `tap`-утилита дают тактильный фидбек.
- Семантика: `<header>`, `<nav>`, `<main>`, `<aside>`, `<section>`, `<footer>`, `<ol>`/`<ul>`, заголовки по уровням.

### 3.4 Состояния
- Спиннер показан только пока данных нет, `EmptyState` для случая «загружено, но пусто».
- `aria-label="Загрузка"` на спиннере.
- `Reveal` срабатывает через `whileInView` + `once: true` — без повторов.

### 3.5 Адаптивность
- Mobile: гамбургер-меню, шапка `sticky top-0`, один столбец.
- `md` (≥768): переход на левый `PublicSidebar` (sticky, 240px) + основной контейнер. Сайдбар скрыт на мобильном, шапка — на десктопе.
- `lg`: расширенные отступы `container-x`, hero-картинка 380 вместо 320, сетки 3 колонки.

### 3.6 Брендовая атмосфера
- `brand-gradient` + `noise` + `grid-lines` в герое и `RaceWeatherCard` дают «гоночно-журнальную» эстетику без перебора.

### 3.7 Производительность
- `fetchPriority="high"` на hero-cover.
- `loading="lazy"` + `decoding="async"` на второстепенных изображениях.
- `Reveal` через `whileInView` + `viewport once: true` — без лишней работы.

## 5. Доступность (a11y) — отдельный чек-лист

- ✅ Семантическая разметка: `<header>`, `<main>`, `<aside>`, `<section>`, `<footer>`, `<nav>`.
- ✅ `aria-label` на кнопках без текста (меню, табы баннеров).
- ✅ `aria-expanded` на бургере.
- ✅ `aria-hidden` на декоративных изображениях героя/погоды.
- ✅ `:focus-visible` — глобально проставляется brand-обводка.
- ✅ `prefers-reduced-motion` уважается глобально (но анимированные gif — см. H1).
- ❌ Нет skip-link.
- ❌ `Hall of Fame` карточки — визуально «выглядят как карточки», но не помечены как ссылки/кнопки.
- ⚠️ Контраст `text-fg/85`, `text-fg/70`, `text-muted/80` — на грани AA для мелкого текста (12–13px).
